## 🚀 **Your First Task**

When you get your first task:

1. **Read Task**: What are you building?
2. **Plan**: Follow [Planning Protocol](./protocols/planning-protocol.md)
3. **Checkpoint** (if uncertain): See [Human Checkpoint](./protocols/human-checkpoint.md)
4. **Execute**: Create feature branch, write tests, implement
5. **Review**: Follow [Review Protocol](./protocols/review-protocol.md)
6. **Submit**: Create PR with explanation
