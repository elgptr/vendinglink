## 🎓 Key Concepts Embedded

### **Rule Zero (4 Non-Negotiable Principles)**
```
1. Transparency First       → Always explain reasoning
2. Quality Before Speed     → Tests over shortcuts
3. Humans Decide           → Ask before deciding alone
4. Project Over Performance → Follow conventions
```

### **5-Stage Task Protocol**
```
UNDERSTAND (2-3 min)
    ↓ Read & clarify requirements
PLAN (3-5 min)
    ↓ Write approach, flag uncertainties
CHECKPOINT (if needed)
    ↓ Get human approval
EXECUTE (varies)
    ↓ Build incrementally with tests
DELIVER (5-10 min)
    ↓ Submit for review
```

### **Clear Role Definitions**
```
Dev Agent           →    Write code, fix bugs, review code
QA Agent            →    Write tests, verify quality, catch bugs
```

## ✨ Design Excellence

### **✅ DRY (Don't Repeat Yourself)**
- Agent docs LINK to existing docs (no duplication)
- Shared content (architecture, operations, testing)
- Single source of truth

### **✅ Dual Entry Points**
- Humans: `guides/` (getting-started, development-setup, etc.)
- Agents: `agent-guides/` (onboarding, protocol, FAQ, etc.)
- Both: Shared `architecture/`, `operations/`, `testing/`

### **✅ Clear Boundaries**
- Dev agents know their responsibilities
- QA agents know their responsibilities  
- No confusion or overlap

### **✅ Transparent Process**
- Same 5-stage protocol for every task
- Checkpoint happens when uncertain
- Clear decision matrix
- No arbitrary rules
