## ✨ Key Features Implemented

### Rule Zero (Non-Negotiable)
1. **Transparency First** — Explain reasoning
2. **Quality Before Speed** — Tests over shortcuts
3. **Humans Decide, Agents Execute** — Ask before deciding
4. **Project Over Performance** — Follow conventions

### 5-Stage Task Protocol
1. **Understand** (2-3 min)
2. **Plan** (3-5 min) → Created written plan
3. **Checkpoint** (if uncertain) → Get approval
4. **Execute** (varies)
5. **Deliver** (5-10 min) → Submit for review

### Role-Specific Guides
- **Dev Agent:** Knows how to implement features, write tests, review code
- **QA Agent:** Knows how to test, catch bugs, verify quality
