## 🌟 Key Features

### Rule Zero (4 Principles)
1. **Transparency First** — Explain reasoning
2. **Quality Before Speed** — Tests over shortcuts
3. **Humans Decide, Agents Execute** — Ask before deciding
4. **Project Over Performance** — Follow conventions

### 5-Stage Task Protocol
1. **Understand** (2-3 min) — Read & clarify requirements
2. **Plan** (3-5 min) — Write approach, identify uncertainties
3. **Checkpoint** (if uncertain) — Get human approval
4. **Execute** (varies) — Build incrementally with tests
5. **Deliver** (5-10 min) — Submit for review

### Role-Specific Guidance
- **Dev Agent:** Write code, review code, fix bugs
- **QA Agent:** Write tests, verify quality, catch bugs
